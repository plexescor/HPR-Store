# HPR-Store

> **This repository is archived. HPR has been discontinued as of October 26, 2026.**

HPR-Store was the native extension and theme store manager for HPR (Human Pattern Recorder). Since HPR itself is no longer maintained, HPR-Store serves no purpose as a standalone project.

The code remains public under its original license for anyone who wants to fork it or learn from it.
